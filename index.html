Tentang Saya

Saya Roihan Syafiq A.A, biasa dipanggil Sapik, mahasiswa Program Studi Sistem Informasi angkatan 2025 di Universitas Dian Nuswantoro. Saya tertarik pada teknologi, pemrograman, dan pengembangan web, serta senang mempelajari hal baru melalui praktik langsung.

Bidang Teknologi

Saya mempelajari pemrograman dan pembuatan sistem, mulai dari merancang, membangun, hingga memperbaiki kesalahan, dan memandang setiap kendala sebagai bagian dari proses belajar.

Tujuan ke Depan

  • Mengembangkan kompetensi di bidang Sistem Informasi.
  • Menambah pengalaman melalui proyek yang bermanfaat.
  • Menciptakan solusi melalui teknologi.

Proyek Akademik

Tugas dan aktivitas pada mata kuliah Pemrograman Web.

Tugas Pemrograman Web 1

Pembuatan halaman profil dan form interaktif menggunakan elemen semantik HTML, tabel terstruktur, dan berbagai elemen input form.

Rincian teknis
  • Elemen semantik HTML (header, main, section, footer)
  • Tabel terstruktur
  • Form dengan berbagai jenis input
Terkini

Tugas Pemrograman Web 2

Perancangan ulang halaman profil menggunakan CSS dengan layout modern dan tampilan responsif pada desktop maupun perangkat mobile.

Rincian teknis
  • Layout dengan Flexbox dan CSS Grid
  • Tampilan responsif dengan media query
  • Styling elemen serta mode terang dan gelap

Jadwal perkuliahan dan kurikulum tersedia di portal Siadin Udinus.
